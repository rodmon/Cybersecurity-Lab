## Evidence Standard

Each evidence item should:

1. Show the relevant configuration or validation result.
2. Avoid exposing credentials, tokens, private keys or unnecessary personal information.
3. Have a descriptive filename.
4. Be referenced by the README or technical documentation.
5. Be connected to a specific skill or competency.

## Evidence Principle

The objective is not simply to show that a screenshot exists. Each screenshot should answer:

> **What did I do, how was it validated, and what professional skill does this demonstrate?**
