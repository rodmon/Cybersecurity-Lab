# Security and Responsible Testing

This repository documents cybersecurity training and laboratory work.

## Authorization

Security testing must only be conducted against systems and networks for which explicit authorization has been provided.

## Do Not Publish

Do not commit:

- Passwords
- API keys
- Authentication tokens
- Private keys
- VPN credentials
- Personal data
- Production IP addresses where disclosure is not authorized
- Confidential organizational configurations
- Sensitive client information

## Laboratory Boundary

The Week 1 laboratory uses the `10.0.0.0/24` virtual network and Kali Linux at `10.0.0.2/24`.

Future testing should remain inside the authorized laboratory environment unless additional authorization is explicitly provided.
